# Backlory
Backlory is a local Windows desktop application built with C# and Windows Forms. It aims to provide gamers a central place to manage a personal game library, explore different steam games, track achievements and DLC and organise a gaming backlog.
# Planned Features
- Import owned games and playtime from Steam
- Search and explore different steam games
- View game details, achievements and DLC
- Manage your own backlog, ratings and notes
- Track playtime and collection statistics
- Store all data locally
# Project Status
This project is in the very early stages with a single developer working on it, therefore each feature may be implemented a while after the previous. Please take note of this when using the application.
